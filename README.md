파일 메타정보 검사, URL 입력 검사, 조사 범위 설정과 JSON 다운로드를 체험할 수 있습니다. 본문 분석·외부 서비스 조회·파일 전송은 연결하지 않았습니다. 입력은 현재 페이지 메모리에만 보관하며 새로고침하면 초기화됩니다.
