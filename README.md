# Wylie Proposal Lab 문서 분석

등록한 DOCX·TXT·MD와 직접 입력 회의록의 실제 본문을 브라우저에서 읽고, 문서별 상태와 원문 위치를 포함한 후보를 화면에 표시합니다. JSON 다운로드 흐름은 제거했습니다.

요구사항·목표·제약·확인 질문은 문장 규칙에 의한 후보이며, 조사 키워드는 정의된 업무 용어 빈도입니다. AI 의미 분석, ListeningMind 조회, URL 관찰은 아직 연결하지 않았습니다. 본문 문단과 표 안 텍스트를 읽으며 이미지 OCR·머리글·각주 등 전체 시각 문맥을 대체하지 않습니다. 일부 파일 실패 시 읽은 결과는 유지하고 자료 수정 후 재실행할 수 있습니다.

파일은 외부 서버로 전송하지 않습니다. 현재 페이지 메모리만 사용하므로 새로고침 시 입력과 결과가 초기화됩니다. API 인증·작업 저장·서버 분석은 후속 연결 사항입니다.
